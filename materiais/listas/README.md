## Conteúdo por lista

### Lista 1 — Fundamentos

**Revisão (questões 1–12):** definição de grafo, loop, multiaresta, vértice isolado, grafo simples vs. multigrafo, grafo completo, subgrafo, direcionado vs. não direcionado, ponderado, esparso/denso, graus, caminhos.

**Exercícios (questões 13–16):** contagem de arestas em grafos completos, graus em digrafo, desenho de grafos com propriedades específicas.

### Lista 2 — Travessias

**Revisão (questões 1–5):** definição de travessia, DFS vs. BFS, quando coincidem, qual usar para distância em arestas.

**Exercícios (questões 6–7):** executar DFS e BFS em grafo dado (menor rótulo em empate), calcular distâncias entre pares de vértices.

### Lista 3 — Componentes conectados

**Revisão (questões 1–5):** grafo conectado, componente conectado, mínimo/máximo de componentes, BFS vs. DFS para identificação.

**Exercícios (questões 6–7):** contar componentes em grafo dado, construir grafos com n vértices e k componentes.

## Ordem sugerida de estudo

3. Resolver os **exercícios da lista** (sem gabarito — tente primeiro)
4. Comparar com `02-exercicios-comentados.md` do repositório
5. Implementar código quando aplicável
